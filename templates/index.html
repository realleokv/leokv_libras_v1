Texto reconhecido

Uma letra é um sinal. Uma expressão reconhecida é removida por inteiro. Não são acrescentados verbos ou intenções.

Acompanha o reconhecimento até você começar a editar.

    Gravar uma execução

    Use códigos sem nomes pessoais. Grave todos os sinais e “Nenhum sinal” com pelo menos 3 pessoas, 2 execuções por pessoa. Esse é o mínimo técnico, não uma garantia de qualidade.

    Dados da gravação

    Para movimento, execute um gesto completo em aproximadamente 2 segundos. Cada clique salva uma gravação independente.

    Treinar e avaliar

    O sistema separa pessoas entre treinamento, calibração e teste. As gravações usadas no teste não entram no modelo final.
